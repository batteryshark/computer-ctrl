# Optional executor implementation and live acceptance — 2026-10-13

Implemented the opt-in `delegate` contract for labeled native forms/wizards in one explicit window. Callers supply exact fields/values, checkbox states, stage buttons, success predicates and budgets. The executor validates targets before input, gates buttons on readback, rejects stale selections, and returns progress on handoff. A singleton candidate uses deterministic automation; multiple candidates use an optional D3 or OpenAI-compatible choice endpoint. Model runtimes and weights remain outside cctl.

## Verification

- Unit/regression suite: **118 passed** (42 adapter, 28 executor, 9 opt-in integration, 39 existing tests).
- Live acceptance: **Codex CLI 8/8; OpenCode 8/8**. Each actual harness executed `acceptance/system_one_mac.py`, which launched fresh native windows and called the public `delegate` MCP tool. This is real GUI execution through both harnesses, not decision replay. Output files were independently checked for exact values/settings and save action; fresh accessible confirmation proved completion. Each final trial also verified window cleanup; an independent final check found zero remaining test windows (including off-screen) and zero fixture processes.
- Distribution: source archive and wheel built successfully; all five changed/new runtime modules and the packaged tool contract exactly matched tested source. No new ML dependency was added to cctl. The generic chat adapter sends standard request fields; its provider-specific template parameter was removed and covered by a schema assertion.
- Independent code review fixed private intent logging, uncertainty after dispatched input timeout, final-step success reporting and observation-completeness handling. No blocking findings remain.

## Runtime and repairs

Test host: Apple M5 Max, 128 GB unified memory, macOS 27.0.1. Sidecar: `vllm-sr/d3-mini` at pinned revision `6d8971f464d6f9d4c5af7d9a8d75f3aa03be4f59`, BF16 on MPS, PyTorch 2.14.1 / Transformers 5.17.0, full publisher manifest verification. The loopback sidecar reused the isolated cached test environment; no model service was enabled in user configuration.

The first native smoke stopped because Cua reports `elements_complete: false` on AppKit trees despite `truncated: false`, zero pending nodes and matching returned/total/actual row counts. The compatibility exception accepts positive observed-target checks under exactly those Mac conditions. Absence predicates still require explicit completeness; empty and truncated trees return control. A second smoke returned control because the choice prompt did not explain that cctl already owned all field values. Trusted candidate metadata and conditional instructions now explain that each eligible action is prevalidated and currently necessary, and the chooser selects order only. These repairs preceded both complete acceptance runs.

Codex's first suite invocation could not compile Swift in its default shell sandbox; no trials ran. The final run used automatic approval review for native windows, loopback sockets and module-cache writes. OpenCode used its configured free `opencode/ling-3.1-flash-free` provider. The first full functional runs passed, but the acceptance runner supplied an unsupported argument to the close tool and did not check its error. The leftover test windows were closed, the runner now fails on cleanup errors and verifies disappearance from a fresh list, and both full suites were repeated. The linked JSON files are those final runs, with cleanup_verified=true on every trial. Neither harness changed credentials or provider configuration. The suite definitions were fixed before execution, but this is implementation acceptance after iterative repairs, not a blind benchmark.

## Scope and next work

The feature stays experimental and disabled by default. It supports exact nonempty accessibility labels and caller-defined stages; task text orders already-authorized actions. It does not provide general goal-only planning, unlabeled editor control, browser DOM execution, pixel grounding, menus, or parent-agent recovery. Unknown/unsupported UI states return control. Observation and native dispatch remain separate operations; cancellation cannot undo an input already sent. Action summaries report attempted/acknowledged/confirmed/refused/uncertain input without recording supplied field values or private intent.

Mac acceptance is complete. Run frozen longer workflows in existing apps and native Linux/Windows acceptance before widening the scope. Keep cross-platform browser/eval work on the tracker. Test-owned windows were closed and the temporary sidecar stopped after verification; cached weights remain for reproducibility.
